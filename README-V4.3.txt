U250 V4.3 — Uniform Albums

Mudança principal:
- seção Discography refeita do zero dentro da arquitetura V4;
- todas as 16 capas agora usam exatamente o mesmo formato quadrado (1:1);

Nenhuma outra área visual do site foi redesenhada nesta versão.
